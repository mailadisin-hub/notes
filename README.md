# Notes

The web version of Notes: iPhone-style notes with handwriting, PDFs you can
write on, Markdown vaults and live shared pages.

**Open it: https://mailadisin-hub.github.io/notes/**

- **iPhone and iPad:** open the link in Safari, tap Share, then **Add to Home
  Screen**. It opens full screen like an app and works offline.
- **Mac:** open it in Safari, then File > **Add to Dock** (macOS Sonoma or
  later). In Chrome, use the install button in the address bar.

Sign in with the same account as the Android and Windows apps and your notes
sync between all of them.

This repository is generated. It is the `src/` folder of the Notes project,
published by `publish-web.ps1`, so change the project rather than this.
